* For NOMISMA display
* File to choose the messages of the user display,
* According to the sequence of passage of the vehicle.
* Each line is made up of a label delimited by quotation marks
* And possibly containing one or more printing formatters
* For one or more variable (s).
*
* This label will be displayed on both lines of the display
* Note: Format and font of the line depends of length formatters!
* Example: %2lu formatter always takes 2 characters on the displayed line
*
* The pass sequence is identified by a previous keyword of $
* Known keywords are:
*   AFF_SOFT_REV        // Software version
*   AFF_YEAR            //  \
*   AFF_MONTH           //  |
*   AFF_DAY             //  |  Date and
*   AFF_HOUR            //  |  time
*   AFF_MINUTE          //  |
*   AFF_SECOND          //  /
*   AFF_PAYMENT_TYPE    // Payment type
*   AFF_CLASS           // Vehicle class
*   AFF_FARE_INT        // Associated tariff (integer part)
*   AFF_FARE_DEC        // Associated rate (decimal part)
*   AFF_PAID_INT        // Amount paid (integer part)
*   AFF_PAID_DEC        // Amount paid (decimal part)
*   AFF_SALEFARE_INT    // Sale tariff (integer part)
*   AFF_SALEFARE_DEC    // Sale tariff (integer part)
*   AFF_SALEPAID_INT    // Amount Paid for Sale (integer part)
*   AFF_SALEPAID_DEC    // Amount paid for sale (decimal part)
*   AFF_LIBELLE1        // Dynamic label
*   AFF_LIBELLE2        // Dynamic label
*   AFF_LIBELLE3        // Dynamic label
*
* A line of the display corresponds to	… 40 characters in police A (One string, first 20 characters is in first row, last 20 characters is in second row)
*                                  		… 15 characters in police B
*                                  		… 30 characters in police C (One string, first 6 characters is big caps, next 12 characters is in first row, last 12 characters is in second row)
* Lines have to be filled with spaces to the end!
*
* The separation of the lines is not indicated in the label.
*
* Note: -Pound character for this display is A3h, euro character is 80h.
*
* Example of a message for a closed lane:
* $CLOSED
* "<------------->"
* B" CLOSED LANE  "
*
* ANY LINE BEGINNING BY * IS CONSIDERED LINE OF COMMENTS
* AND IS THEREFORE IGNORED.
