* Pour Afficheur SAGEM
* Fichier permettant de choisir les messages de l'afficheur usager,
* selon la sequence de passage du vehicule.
* Chaque ligne est constituee d'un libelle delimite par des guillemets
* et contenant eventuellement un ou plusieurs formatteurs d'impression
* pour une ou plusieurs variable(s).
* C'est ce libelle qui sera affiche sur les deux lignes de l'afficheur
*  Remarque : pour les formatteurs la longueur depend du format et de
*             la police de la ligne!
*  Exemple  : formatteur %2lu prend toujours 2 caracteres sur la ligne
*             affichee
* La sequence de passage est identifiee par un mot cle precede de $
* Les mots cle connu sont les suivants :
*   AFF_SOFT_REV        // Version soft VM
*   AFF_YEAR            //  \
*   AFF_MONTH           //  |
*   AFF_DAY             //  |  Date et
*   AFF_HOUR            //  |  Heure
*   AFF_MINUTE          //  |
*   AFF_SECOND          //  /
*   AFF_PAYMENT_TYPE    // Type de payment utilise
*   AFF_CLASS           // Classe du vehicule
*   AFF_FARE_INT        // Tarif associe (partie entiere)
*   AFF_FARE_DEC        // Tarif associe (partie decimale)
*   AFF_PAID_INT        // Montant paye (partie entiere)
*   AFF_PAID_DEC        // Montant paye (partie decimale)
*   AFF_SALEFARE_INT    // Tarif de la vente (partie entiere)
*   AFF_SALEFARE_DEC    // Tarif de la vente (partie decimale)
*   AFF_SALEPAID_INT    // Montant paye pour la vente (partie entiere)
*   AFF_SALEPAID_DEC    // Montant paye pour la vente (partie decimale)
*   AFF_LIBELLE1        // Libelle dynamique
*   AFF_LIBELLE2        // Libelle dynamique
*   AFF_LIBELLE3        // Libelle dynamique
*
* Une ligne de l'afficheur correspond … 20 caracteres en police A
*                                  et … 15 caracteres en police B
* la separation des lignes n'est pas indiquee dans le libelle
* Exemple d'un message pour une voie fermee:
* $CLOSED
* "CERRADO  "
* ""
*
* TOUTE LIGNE COMMENCANT PAR * EST CONSIDEREE COMME LIGNE DE COMMENTAIRES
* ET EST DONC IGNOREE.
