2.0.1   - NBL - 13/11/2001
		Ajout d'un hook par défaut permettant la trace des données échangées
        sur console (par paramétrage à l'aide du paramètre "ConsoleTrace") ou
        vers différents "objets" : fenêtre (par WM), tread (par thread queue),
        et/ou FIFO spécifique.
        Intégration de ces ajouts aux classes COM CSDsrcLib.CSDsrcLinkClass et
        CSDsrcLib.CSDsrcRequestClass. La classe CSDsrcLinkClass permet désormais
        de dissocié l'émission de la requète de sa réception et permet également
        la concaténation de requètes.
        Réalisation d'un simulateur DSRC permettant l'exécution de scripts de
        tests (VBScript) avec une balise ou un ELI.

2.0.2   - NBL - 13/01/2003

        Suppression du WaitFor... dans la boucle infinie du module BAC dans le cas
        où des caractères sont dispos dans le buffer série.

3.0.0   - NBL - 23/04/2003
        
        La compatibilité du code est garantie. Mais du fait du changement de certaines
        constantes et de tailles de structures, une recompilation est nécessaire.
        Pour des raisons de cohabitation entre versions majeurs et de compatibilité
        binaire sur les classes OLE, les fichiers CSDsrcLibrary.DLL et CSR_TAG.DLL
        changent donc de nom et deviennent CSDsrcLib3.DLL et CSR_TAG3.DLL. Le nom de
        la librairie OLE devient CSDsrcLib3.

        Les principales évolutions de CSR_TAG3.DLL sont :
    
          Changement des valeurs CENL7_MAX_ATTR_BYTES et CENL7_MAX_APP_PARAM_BYTES.
          
          Ajout des actions ADD/SUB/GETSECURE/SETSECURE.
          
          Evolution de la fonction TagOpen() pour prendre en compte les construction
          de paramètres de communication par les nouvelles fonctions
          TagBuildCommunicatorParams() et TagBuildWiredParams().
          
          Ajout de la fonction TagIsVersionCompatible() principalement pour permettre
          à l'encapsulation OLE de détecter la version utilisée.
          
          Attention, les "SUBSTRACT" (faute d'ortaugrafe) deviennent "SUBTRACT".
          
          Il est mainteant possible d'envoyer des requètes vides par le mode transparent.

          Lors de la réception d'un message DSRC contenant plusieurs réponses ou contenant
          des données parasites à la fin, il est également possible de tronquer l'analyse
          après un nombre choisi de morceaux.

        Les principales évolutions de CSDsrcLib3.DLL sont :

          Changement des tailles de structure pour coller aux structure de la librairie C.
          Ajout des actions ADD/SUB/GETSECURE/SETSECURE.
          Possibilité de paramétrer la communication autrement que par le registre
          avec l'ajout des deux méthodes SetBeaconParameters() et SetWiredParameters().
          Possibilité d'activer les traces console autremant qu'avec le registre
          à l'aide de la propriété "ConsoleTrace".
          Attention, les "SUBSTRACT" (faute d'ortaugrafe) deviennent "SUBTRACT".

3.5.0 - NBL - 02/2007

  C DLL :
    Added the ability to send custom interface requests and received custom responses from the TAG API thanks to the new
    TagInterfaceRequestEx.
    Added the abitily to change the behaviours in case of message collision with the BAC protocol.
    In this case, the asynchronous error code returned is ERROR_CANCELLED.
  OLE CLASS :
    Added the ability to send custom interface requests using the new InterfaceCustomCommand method.
    Added the abitily to change the behaviours in case of message collision with the BAC protocol using
    the new property CollisionCancel. In this case, the asynchronous error code returned is
    ERROR_CANCELLED + DsrcErrorSubModuleBase.
